뜻을 아는 것과 문장 안에서 판단하는 것은 다르다

현재는 본문 내용을 대략 이해하지만, 문제를 풀 때 근거 문장을 다시 찾는 과정이 약한 상태다. 예를 들어 전치사가 포함된 문장을 그림이나 상황과 연결해야 할 때, 학생은 전치사의 익숙한 뜻을 먼저 고정한다. 답지를 가리고 재풀이하면 비교 대상 두 개와 기준을 구분하지 못해 그림 설명의 방향을 반대로 잡기도 한다.

비교문에서도 비슷한 오류가 생긴다. 두 대상을 비교해야 하는데 무엇과 무엇을 비교하는지 표시하지 않고 단어를 우리말 순서대로 배열한다. 그래서 문법 형태를 외웠더라도 문장의 실제 의미가 바뀌는 상황에서 멈춘다. 본문 선택지에서는 내용을 읽었다고 생각하지만, 선택지를 뒷받침하는 문장을 교과서에서 다시 찾지 않고 기억에 의존해 고른다.

비교 대상과 기준을 먼저 적어 보는 연습

비교문을 연습할 때 바로 정답 문장을 쓰지 않는다. 먼저 종이에 비교 대상 두 개를 나란히 적고, 무엇을 기준으로 비교하는지 한 단어로 표시한다. 예를 들어 두 사람의 키를 비교한다면 ‘대상 A’, ‘대상 B’, ‘기준: 키’를 구분한다. 그다음 주어와 비교 대상의 위치를 확인하고, 빈칸에 들어갈 형용사나 비교 표현을 말한 뒤 문장을 완성한다.

본문 문제에서는 선택지를 읽기 전에 관련 문장을 찾는다. 찾은 문장에 주어, 동사, 전치사구를 각각 표시하고 선택지의 내용과 비교한다. 답을 맞혔더라도 근거 문장을 표시하지 못하면 다시 본문으로 돌아가야 한다. 서술형에서는 우리말 뜻을 영어로 옮기기 전에 주어와 동사를 먼저 적고, 필요한 전치사와 비교 기준을 뒤에 붙인다.
