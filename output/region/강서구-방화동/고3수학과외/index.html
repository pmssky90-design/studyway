답안에는 다음과 같이 적혀 있었다.

0.272727… = 0.27 + 0.27 + 0.27 + ⋯

이 식은 오답이다. 오른쪽 식은 공비가 1인 급수이므로 수렴하지 않으며, 실제 소수의 각 항도 소수점 아래 두 자리씩 이동하지 않는다. 반복되는 27을 자리값에 맞게 분리하면

이므로 첫째항은 a = 0.27, 공비는 r = 0.01이다. |r|<1이므로 무한등비급수의 합은

S = a}{1-r} = \frac{0.27}{1-0.01} = \frac{0.27}{0.99} = \frac{27}{99} = \frac{3}{11}
