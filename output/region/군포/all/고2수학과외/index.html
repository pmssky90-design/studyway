예를 들어 삼각형 ABC에서 a=BC=6, b=CA=8, A=30°, B=45°일 때 사인법칙은 다음처럼 대응시킨다.

a/sin A = b/sin B

왜냐하면 변 a는 각 A의 맞은편에 있고, 변 b는 각 B의 맞은편에 있기 때문이다. 따라서

6/sin 30° = 8/sin 45°

이어지는 계산은

6/(1/2) = 8/(√2/2), 즉 12 = 8√2가 된다. 이 값들이 서로 같지 않으므로 주어진 네 조건은 하나의 삼각형에 동시에 성립할 수 없다. 이처럼 대응을 올바르게 적었다고 해서 주어진 수치가 반드시 가능한 것은 아니며, 계산 결과의 일치 여부도 확인해야 한다.

a/sin A가 아니라 a/sin B로 놓인 순간

풀이 흔적에 a/sin A = b/sin B 대신 a/sin B = b/sin A가 적혀 있다면, 이는 단순한 계산 실수가 아니라 변과 각의 맞은편 관계를 확인하지 않은 것이다. 실제로 이 식을 위의 값에 적용하면

6/sin 45° = 8/sin 30°

가 되어 3√2 = 16이라는 잘못된 관계가 나온다. a와 B를 한 쌍으로 묶은 근거가 없으므로, 이후 계산을 계속해도 올바른 삼각형의 정보를 이용한 풀이가 아니다. 사인법칙은 아무 변과 아무 각을 짝짓는 공식이 아니라 반드시 서로 마주 보는 변과 각을 연결한다.

b=CA ↔ B

b = 10·sin60°/sin30° = 10·(√3/2)/(1/2) = 10√3
