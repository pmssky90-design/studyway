이의고등학교의 학교 프린트나 교과서 문제에서 합집합을 다룰 때는 원소를 모두 적는 것보다 같은 원소를 중복 없이 모으는지가 먼저 확인되어야 한다. 수원시 영통구 하동 생활권에서도 학교와 주거지 사이 이동 시간에 따라 짧은 학습 시간을 쓰는 방식이 달라질 수 있으므로, 한 문제를 풀 때 어떤 판단을 했는지 분명히 남기는 연습이 필요하다.

두 목록을 이어 붙이면 합집합이 되지 않는 이유

예를 들어

A = {1, 3, 5, 7}, B = {3, 6, 7}

일 때 합집합은 두 집합에 들어 있는 원소를 한데 모은 집합이다.

A ∪ B = {1, 3, 5, 6, 7}

3과 7은 A와 B에 모두 들어 있지만, 합집합에서는 각각 한 번만 쓴다. 집합은 같은 원소를 여러 번 적어도 서로 다른 원소로 세지 않기 때문이다.

합집합을 만들 때는 A의 원소를 먼저 적은 뒤, B에서 아직 나오지 않은 원소만 추가한다.

체크 표시 없이 공통 원소를 두 번 적은 풀이

수업 중 한 학생은 다음과 같이 적었다.

A ∪ B = {1, 3, 5, 7, 3, 6, 7}

두 집합의 원소를 빠뜨리지는 않았지만, 3과 7을 두 번 기록했다. 이 풀이에서 빠진 것은 계산 과정이 아니라 공통 원소를 확인하는 단계다. 공통 원소에 별도 표시가 없으니 A를 적은 뒤 B를 그대로 이어 쓴 것이다.

따라서 오답을 고칠 때는 정답만 지우고 다시 쓰지 않는다. B의 원소를 하나씩 보면서 이미 적힌 원소인지 확인한다. 3은 A에 있으므로 추가하지 않고, 6은 없으므로 추가하며, 7도 이미 있으므로 제외한다. 그 결과는 {1, 3, 5, 6, 7}이다.

‘중복 없이 모으기’를 풀이 안에 남기는 방법

공통 원소에 동그라미나 체크 표시를 하면서 다음처럼 정리할 수 있다.

  • A의 원소: 1, 3, 5, 7
  • B의 원소 3: 이미 적었으므로 제외
  • B의 원소 6: 처음 나오므로 추가
  • B의 원소 7: 이미 적었으므로 제외

이 기록은 단순한 표시가 아니라 합집합의 정의를 실제 행동으로 바꾼 것이다. 학생이 문제를 보자마자 공통 원소에 먼저 표시하고, 그 뒤에 새로운 원소만 옮겨 적는다면 이전처럼 두 목록을 무조건 연결하는 오류를 줄일 수 있다.

표현이 달라진 프린트에서도 판단 확인하기

학교 프린트에서 집합을 문자로 나타내거나 원소의 순서를 바꾸어 제시할 수 있다.

C = {가, 다, 라}, D = {라, 마, 바}

라가 두 집합에 공통으로 들어 있으므로

C ∪ D = {가, 다, 라, 마, 바}

이다. 순서를 바꾸어 {마, 바, 가, 다, 라}처럼 써도 같은 집합이지만, 라를 두 번 쓰면 합집합의 원소를 중복 없이 모았다고 볼 수 없다. 답을 바로 알려주기보다 학생이 “라가 두 집합에 모두 있으므로 한 번만 남겼다”라고 설명하는지 확인한다.

정답을 맞혔더라도 공통 원소를 확인하고 표시하는 데 오래 걸렸다면 아직 해당 판단이 안정되었다고 기록하지 않는다. 다음 문제에서 같은 표시와 설명을 스스로 다시 사용하는지까지 살펴야 한다.

짧은 학습 시간에 남길 한 줄

귀가 후 시간이 넉넉한 학생은 여러 집합을 비교할 수 있지만, 이동 시간이 긴 학생은 한 문제를 푼 뒤 다음 문장을 적는 방식으로도 충분히 확인할 수 있다.

“두 집합에 모두 있는 원소는 한 번만 남기고, 한쪽에만 있는 원소는 모두 추가했다.”

이 문장이 실제 원소와 일치하는지 검토하면 합집합을 단순히 두 목록을 이어 쓰는 작업으로 처리했는지 확인할 수 있다.
