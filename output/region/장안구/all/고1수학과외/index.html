교집합의 판단 기준: 원소 하나를 선택했을 때, 그 원소가 A에도 속하고 B에도 속하는가?

기호를 원소별 질문으로 바꾸기

오답을 고칠 때는 두 목록을 한꺼번에 외우기보다 A의 원소를 하나씩 B에서 확인한다.

  • 1: B에 없으므로 제외
  • 3: A와 B에 모두 있으므로 포함
  • 5: B에 없으므로 제외
  • 7: A와 B에 모두 있으므로 포함

그러므로 A ∩ B = {3, 7}이다. 답안에는 결과만 적지 않고 “3과 7은 두 집합에 모두 속한다”라고 근거를 남긴다. 공통 원소만 따로 표시하는 행동이 교집합 문제의 실제 풀이가 된다.

원소가 적은 집합부터 대조하기

C = {2, 6, 9}, D = {1, 2, 5, 6, 10}이라면 C의 원소를 기준으로 D에 있는지 확인하는 편이 빠르다. 2와 6만 두 집합에 속하므로 C ∩ D = {2, 6}이다. 9는 C에는 있지만 D에는 없으므로 포함하지 않는다.

반대로 두 집합을 합치는 합집합과 혼동하면 안 된다. 이 경우 C ∪ D = {1, 2, 5, 6, 9, 10}이지만, 교집합은 공통 부분인 {2, 6}만 남긴다.
