n!을 쓴 순간 조건이 사라졌다

전체 배열 수 = 6! = 720

이 식은 오답이다. 일렬로 세우는 경우에는 6!이지만, 원탁에서는 회전한 배열을 같은 배치로 처리한다. 예를 들어 A를 기준으로 고정하면 나머지 다섯 명만 배열하면 되므로 전체 경우의 수는

(6-1)! = 5! = 120

이다. 학생은 채점 후 풀이 전체를 다시 쓰지 않고, 먼저 6!을 쓴 첫 줄에 표시해야 했다. 그다음 ‘원탁, 회전 동일’이라는 조건에서 한 사람을 고정한다는 화살표를 그렸다.

원탁에서 회전 동일 → A 고정 → 나머지 5명 배열 → 5! = 120

인접 조건까지 연결한 수정 풀이

같은 6명이 원탁에 앉을 때 A와 B가 서로 이웃하지 않는 경우를 구하면, 전체 경우에서 인접한 경우를 빼야 한다.

  • 전체: A를 고정하므로 5! = 120
  • A와 B가 인접: B는 A의 왼쪽 또는 오른쪽이므로 2 × 4! = 48
  • 이웃하지 않는 경우: 5! - 2 × 4! = 120 - 48 = 72
