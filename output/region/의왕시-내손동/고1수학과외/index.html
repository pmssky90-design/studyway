역수를 쓴 순간 바뀌어 버린 함수

학교 프린트에서 다음 일차함수의 역함수를 구하는 문제를 다뤘다.

f(x) = (3x - 2) / 5

학생은 풀이에 f-1(x) = 1/f(x)라고 적었다. 그러나 역함수의 기호에서 위첨자 -1은 역수를 뜻하지 않는다. 역함수는 함수의 입력과 출력 관계를 거꾸로 만든 함수다.

이 학생의 풀이에서는 x와 y를 교환하는 과정이 빠졌고, 역함수를 구한 뒤 합성으로 확인하는 표시도 없었다. 따라서 현재 상태는 공식을 외운 정도가 아니라, 함수와 역수의 의미를 구분하고 풀이 순서를 실행하는 단계로 넘어가야 하는 상태로 볼 수 있다.

x와 y를 바꾸어 관계의 방향을 뒤집기

먼저 y=f(x)로 놓는다.

y = (3x - 2) / 5

입력과 출력의 역할을 바꾸기 위해 x와 y를 교환하면

x = (3y - 2) / 5

이제 y에 대해 정리한다.

5x = 3y - 2
3y = 5x + 2
y = (5x + 2) / 3

따라서

f-1(x) = (5x + 2) / 3

이다. 원래 함수의 기울기가 3/5로 0이 아니므로 일대일 대응이 성립하고, 역함수를 일차함수로 나타낼 수 있다.

합성 결과가 x로 돌아오는지 계산하기

구한 식을 그대로 믿지 않고 양방향 합성을 확인한다.

f(f-1(x)) = f((5x + 2)/3)

원래 함수에 대입하면

((3(5x + 2)/3) - 2) / 5
= ((5x + 2) - 2) / 5
= x

반대 순서도 계산하면

f-1(f(x)) = f-1((3x - 2)/5)

= (5((3x - 2)/5) + 2) / 3
= (3x - 2 + 2) / 3
= x

두 합성이 모두 x가 되므로 두 식은 서로 역함수 관계임을 확인할 수 있다. 이 검산은 단순 계산 반복이 아니라, 입력과 출력의 방향을 제대로 바꾸었는지 확인하는 절차다.

새 문제를 풀 때는 식 옆에 다음과 같은 짧은 표시를 남긴다.

  • y=f(x)로 놓기
  • x와 y 교환하기
  • y에 대하여 정리하기
  • f(f-1(x)) 또는 f-1(f(x)) 계산하기

예를 들어 g(x) = (4x + 7)/3이라면

순서가 섞인 서술형에서 확인하기

검증 문제는 같은 식을 다시 제시하지 않고, 풀이 단계의 순서를 섞어 제시한다. 예를 들어 h(x) = (2x - 5)/7에 대해 다음 문장을 올바른 순서로 배열하게 한다.

  • y = (7x + 5)/2

  • 7x = 2y - 5
  • y = (2x - 5)/7

정확한 배열은 원래 식을 쓰고, x와 y를 교환한 뒤, 7x = 2y - 5를 거쳐 y = (7x + 5)/2에 도달하는 순서다. 그다음 h(h-1(x))를 계산하여 x가 되는지 확인해야 한다.

채점할 때는 정답 식만 보지 않는다. 개념 항목에서는 역수로 처리하지 않았는지, 조건 항목에서는 일차함수의 기울기가 0이 아닌지, 계산 항목에서는 괄호와 분배가 정확한지, 표현 항목에서는 교환 과정과 합성 근거를 적었는지를 각각 확인한다. 결론만 맞고 근거가 빠졌다면 역함수 검산 과정은 아직 안정된 것으로 보지 않는다.
