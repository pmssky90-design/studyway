잘하는 과목과 약한 과목의 기준을 다르게 세우기

마지막 내신에서는 모든 과목을 같은 방식으로 끌어올리기보다 유지선과 복구선을 나누는 편이 현실적이다. 잘하는 과목은 새로운 문제를 계속 추가하기보다 학교 자료의 서술형 답안을 완성하고, 맞힌 문제 중 풀이가 불안정한 것만 다시 확인한다. 반대로 약한 과목은 전 범위를 처음부터 반복하지 않고 현재 시험문제를 막는 선수개념부터 역추적한다.

  • 수학: 답지를 보면 이해되지만 다음 날 혼자 첫 식을 세우지 못하는 단원을 표시하고, 개념 한 줄과 첫 단계만 가린 채 재현한다.

  • 국어: 작품이나 지문을 읽었다는 데 그치지 않고, 답의 근거가 되는 문장을 찾아 두 문장으로 설명한다.
  • 과학·사회: 용어를 외운 뒤 현상이나 자료와 연결해 “왜 그런가”를 한 문장으로 말하고 학교 학습지에 다시 적용한다.

중1·중2 공백이 보이면 관련 단원 전체를 다시 시작할 필요는 없다. 예를 들어 중3 함수 문제에서 좌표와 비례 개념이 막힌다면 해당 선수개념을 짧게 복습한 뒤 현재 함수 문제에 적용한다. 같은 유형을 혼자 풀 수 있고 설명까지 가능해지면 과거 복습을 종료하고 중3 범위로 돌아온다.
