계수가 아니라 항 전체를 보고 분류해야 하는 이유

다음 식을 정리해 보자.

3x - 2y + 5x + 7 - 4y - 3 + 2x

같은 문자를 포함하고 문자 부분이 같은 항끼리 묶으면

(3x + 5x + 2x) + (-2y - 4y) + (7 - 3)

가 된다. 따라서 결과는 10x - 6y + 4이다. x항의 계수는 3, 5, 2이므로 합이 10이고, y항의 계수는 -2, -4이므로 합이 -6이다. 상수항 7과 -3은 문자 부분이 없으므로 따로 계산한다.

답은 맞아도 묶은 근거가 사라진 답안

관찰된 풀이에서는 학생이 위 식을 한 줄씩 계산하다가 3x + 5x = 8x까지만 적고, 뒤의 2x를 놓쳤다. 이후 y항과 상수항을 계산해 8x - 6y + 4를 답으로 남겼다. 답을 다시 적을 때도 같은 문자 부분을 모두 모았다는 표시 없이 바로 다음 계산으로 넘어갔다.

이 장면은 계산법을 전혀 모르는 경우라기보다, 항의 개수가 많아졌을 때 같은 문자 부분을 색인 없이 정확히 모으는 과정이 아직 안정되지 않았다는 뜻이다. 특히 x항을 앞에서 발견한 두 개만 처리하고 식 뒤쪽의 항을 확인하지 않은 것이 실제 오답으로 이어졌다.

색인 대신 문자 부분을 기준으로 식을 다시 읽기

항에 번호를 붙이지 않아도 식을 세 묶음으로 나눌 수 있다.

  • x를 포함한 항: 3x, 5x, 2x
  • y를 포함한 항: -2y, -4y
  • 상수항: 7, -3

풀이 중간에는 계산 결과만 남기지 말고, 실제로 모은 항을 한 번 적는다.

x항: 3x + 5x + 2x = 10x
y항: -2y - 4y = -6y
상수항: 7 - 3 = 4

그 뒤 10x - 6y + 4를 쓴다. 여기서 3x와 5x를 합칠 수 있는 것은 문자 부분이 둘 다 x이기 때문이며, 3x와 -2y처럼 문자 부분이 다른 항은 하나의 항으로 합칠 수 없다.

오답노트에는 정답보다 바뀐 행동을 남긴다

이 학생에게 필요한 기록은 “정답은 10x - 6y + 4”라는 문장이 아니다. 식을 보기 전에 “x항·y항·상수항을 빠짐없이 모은 뒤 계산한다”라는 행동 한 가지를 남기는 것이다. 실제 풀이에서는 각 묶음을 눈으로 확인한 뒤 다음 계산으로 넘어가게 한다.

짧은 연습으로 4a - 3b + 6 - 2a + 5b - 1 + 7a를 정리하면, a항은 4a, -2a, 7a이므로 9a, b항은 -3b, 5b이므로 2b, 상수항은 5이다. 결과는 9a + 2b + 5이다. 이때도 묶은 항을 먼저 적었는지 확인한다.

다른 단원에서도 빠진 요소를 역으로 찾는가

같은 확인 행동이 식 정리에만 머무는지 보려면 소인수분해 결과를 역으로 곱하게 할 수 있다. 예를 들어 84 = 2² × 3 × 7을 적었다면, 2 × 2 × 3 × 7 = 84로 되돌려 곱한다. 곱셈 결과가 84가 아니면 빠진 소인수나 지수를 스스로 찾는다.

이 과정에서도 결과만 보고 넘어가지 않고, 구성 요소를 빠짐없이 모았는지 확인한다는 같은 행동이 나타나야 한다.

좌표가 바뀐 그래프에서 확인할 장면

마지막 확인은 같은 식을 반복하지 않고 좌표값을 바꾼 그래프 문제로 진행한다. 예를 들어 직선 y = -2x + 5에서 x = 1일 때의 점을 묻는다. 학생이 식의 항을 빠뜨리지 않고 대입하면 y = -2(1) + 5 = 3이므로 점은 (1, 3)이다.

이 점을 그래프에 표시한 뒤 x좌표 1과 y좌표 3을 바꾸지 않았는지, 직선 위에 놓이는지 확인한다. 소인수분해에서는 역곱셈으로 빠진 인자를 찾고, 그래프에서는 대입값과 좌표를 다시 확인한다. 두 활동에서 공통으로 확인 흔적을 남기며 계산을 끝내는지가 독립 적용 여부를 판단하는 기준이 된다.
