숫자를 넣기 전에 표시부터 나눈다

예를 들어 “a=−2일 때 3a−4의 값을 구하여라.”라는 문제가 있다. 학생이 흔히 쓰는 오답은 다음과 같다.

3−2−4=−3

이 풀이에서는 a에 −2를 넣었다는 흔적이 없고, 3a를 숫자 3과 a로 따로 읽었다. 먼저 문제 옆에 주어진 것: a=−2, 구할 것: 3a−4의 값이라고 나눈다. 그다음 식의 a 자리에 괄호를 사용해 다음처럼 쓴다.

3a−4 = 3(−2)−4 = −6−4 = −10

괄호는 음수를 대입했다는 사실을 보존한다. ‘3a’를 3과 −2를 이어 붙이는 것이 아니라 곱셈으로 읽어야 하며, −2 전체가 하나의 수라는 점도 분명해진다. 한 줄에 한 번만 계산하면 부호가 바뀌는 위치를 확인하기 쉬워진다.

동류항 판단과 대입을 섞지 않기

문자를 포함한 식에서 숫자 부분만 보고 항을 합치는 행동도 대입 문제의 시작을 방해한다. 예를 들어 다음 식을 보자.

답지 대신 사용할 ‘시작 표시’
