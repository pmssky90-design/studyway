문제 형식이 바뀌면 무너지는 복합문장 풀이

서대문고3영어과외 학습에서 먼저 확인한 것은 정답률보다 복합문장을 읽는 순서였다. 교과서와 EBS 문장을 대조할 때는 주절을 복원한 뒤 절의 경계를 나누던 학생이, 수능형 빈칸이나 비교·대조 지문으로 바뀌면 중간 단계를 건너뛰었다. 익숙한 문장에서는 구조가 유지됐지만 변형된 문장에서는 정확도가 흔들리는 상태였다.

주절을 찾았다고 생각한 순간의 오류

한 문장에서 학생은 접속사 뒤의 긴 수식부를 먼저 해석한 뒤, 앞부분의 주어와 동사를 다시 연결했다. 그러나 실제 주절의 동사는 관계절 안에 있지 않았고, 비교 대상도 앞선 명사가 아니라 문장 전체의 주장에 해당했다. 학생은 선지 중 ‘두 대상이 같은 방식으로 변화한다’는 내용을 골랐지만, 지문은 한쪽의 변화가 다른 쪽의 판단을 수정한다는 구조였다.

이후 절의 위치를 바꾼 문항에서도 같은 실수가 나타났다. 절 경계를 확인하지 않은 채 주절을 추정하면서, 처음 잘못 잡은 해석이 선지 판단까지 이어졌다. 단순히 문법 용어를 모르는 문제가 아니라, 풀이 순서가 유형에 따라 흔들리는 장면이었다.

세 칸으로 나눈 구조 확인 훈련

수정할 때는 문장마다 풀이 과정을 세 칸으로 나누었다. 첫 칸에는 접속사, 관계사, 분사구문처럼 절의 시작과 끝을 표시했다. 둘째 칸에는 수식어를 잠시 걷어내고 주어와 동사만 남겨 주절을 복원했다. 셋째 칸에서야 선지를 비교하도록 했다.

예를 들어 긴 삽입절이 포함된 문장은 먼저 괄호로 묶고, 주절을 짧은 문장으로 다시 적었다. 그다음 선지의 주체와 서술어가 복원된 주절에 맞는지 확인했다. 정답을 고른 뒤에는 선택지 위치를 바꾸어도 같은 판단이 가능한지 점검했고, 오답 하나를 골라 왜 주절의 주체나 절의 범위를 잘못 해석하게 만드는지도 말로 설명하게 했다.

절 경계 확인 → 주절 복원 판단 → 선택지 비교

새 문장과 다른 문제 형식에서 확인한 변화

기존에 풀었던 예문을 다시 외우는 방식은 사용하지 않았다. 소재와 어휘를 바꾼 새 문장, 정답 위치를 바꾼 선택지, 빈칸 대신 내용추론으로 전환한 문항을 활용했다. 한 문항에서는 관계절이 주절 중간에 들어갔고, 다른 문항에서는 비교 표현이 문장 뒤쪽에 배치됐다.

처음에는 학생이 다시 절의 일부를 주절로 착각했지만, 표시한 경계를 근거로 주어와 동사를 회수한 뒤에는 해석을 수정했다. 제한된 시간 안에서도 선지를 먼저 고르지 않고 구조를 확인했으며, 정답뿐 아니라 오답 선지의 오류까지 설명했다. 문제 형식과 어휘가 달라져도 같은 순서를 유지했다는 점을 통과 기준으로 삼았다.
