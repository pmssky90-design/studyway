학생은 문제를 끝까지 읽기 전에 익숙한 공식을 적는다. 예를 들어 3(x-2) > 9를 보고 괄호를 풀지 않고 지수법칙을 떠올리거나, 2x/5 < 4에서 분모 5를 없애는 과정과 부등호 방향을 설명하지 않은 채 답만 쓰기도 한다. 이때 핵심 오류는 단순 계산 실수가 아니다. 곱셈·나눗셈이 양수인지 음수인지 확인하지 않고, 지금 적용할 개념이 식의 계산인지 부등식의 성질인지 구분하지 못한 것이다.

실제 오답 장면에서 확인할 것

문제: -2x > 6을 풀어라.
학생 풀이: x > -3

학생은 2로 나누어 3을 만든 뒤 음수 부호를 처리하지 않았다. 음수 -2로 양변을 나누면 부등호 방향이 바뀌므로 정확한 해는 x < -3이다. 이 장면을 계산 실수라고만 기록하면 같은 오류가 반복된다. 원인은 음수로 곱하거나 나눌 때 순서가 바뀐다는 부등식의 성질을 적용하지 않은 것이다.

다른 문제 5-3x ≤ 14에서는 양변에서 5를 빼 -3x ≤ 9까지 쓴 뒤, 마지막에 x ≤ -3이라고 답했다. 여기서도 -3으로 나누면서 부등호를 뒤집지 않은 조건 적용 오류가 나타난다. 반대로 4(x+1) > 12에서 x+1 > 3으로 바로 넘어간 뒤 x > 2를 얻는 것은 양수 4로 나눈 것이므로 방향을 바꾸지 않는 올바른 처리다.

첫 줄을 세 칸으로 나누어 쓰는 방법

다음 날 다시 풀 문항은 풀이 전에 종이 위에 세 칸을 만든다.

  • 구할 것: x의 범위인지, 식의 값인지 적는다.
  • 주어진 조건: 곱하거나 나누는 수의 부호, 괄호, 분수와 같은 정보를 표시한다.
  • 사용할 개념: 분배법칙인지, 양변에 같은 수를 더하고 빼는지, 음수로 나누어 부등호를 바꾸는지 적는다.

-(x-4) ≥ 2를 만났다면 먼저 -x+4 ≥ 2로 괄호 앞 음수를 표시한다. 이어 -x ≥ -2를 만든 뒤 음수 -1로 나누므로 x ≤ 2라고 적는다. 각 줄 오른쪽에 ‘음수로 나눔, 방향 전환’이라고 짧게 써서 변화의 이유를 남긴다.

분수 형태에서는 숫자를 무조건 없애지 않는다. x/(-3) > 2라면 양변에 -3을 곱할 때 부등호가 반대로 바뀌어 x < -6이 된다. 반면 분모가 양수인 x/5 < 4는 x < 20이며 방향은 그대로다. 문제 옆에 ‘양수’, ‘음수’를 먼저 표시하는 것이 훈련의 핵심이다.
