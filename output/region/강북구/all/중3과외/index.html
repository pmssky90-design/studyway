답지를 본 뒤 새 교재를 펼치는 장면

중3에서 바꿀 학습 행동

첫째, 답지를 확인하기 전에 막힌 지점을 표시한다. 문제 전체를 못 푼 것인지, 조건을 식으로 바꾸지 못한 것인지, 계산에서 실수한 것인지 구분해야 한다. 답지를 본 뒤에는 풀이를 덮고 같은 문제를 다시 풀어 본다. 맞혔더라도 시간이 지나 다시 풀어 독립적으로 재현되는지 확인한다.

둘째, 오답을 계속 쌓기보다 해결된 문제를 목록에서 빼는 기준을 만든다. 같은 유형을 이틀 간격으로 두 번 혼자 풀고, 풀이 이유를 말이나 짧은 문장으로 설명할 수 있으면 해당 오답의 복습을 종료한다. 반대로 답지의 문장을 그대로 옮기거나 숫자만 바꾸면 다시 막히는 문제는 남겨 둔다. 오답의 개수보다 아직 혼자 시작하지 못하는 문제의 수가 중요하다.

월요일에는 학교 진도와 시험범위를 확인하고, 화요일과 수요일에는 중3 현행 문제 중 혼자 시작하지 못한 것만 골라 재풀이한다. 목요일에는 중1·중2 선수개념을 한 가지 주제로만 보충하고, 금요일에는 학교자료의 서술형 질문에 답을 문장으로 작성한다. 주말에는 새 선행 단원을 많이 나가기보다 한 주 동안 해결된 문제와 남은 문제를 나눈다. 수행평가가 있는 주에는 지필 학습을 완전히 없애지 않고 20~30분의 짧은 재현 연습을 유지한다.
