항의 값이 작아지는 것과 수렴은 다르다

학생은 다음 수열의 수렴 여부를 묻는 문제에서 계산 중간에 다음과 같이 적었다.

an = (-1)n이므로 항이 0으로 가까워진다.

이 식은 오답이다. n이 홀수이면 an = -1, n이 짝수이면 an = 1이므로 항은 0에 가까워지지 않는다. 실제 항은 -1과 1 사이에서 계속 바뀐다.

수열이 어떤 실수 L로 수렴하려면 모든 충분히 큰 n에 대해 an이 L에 가까워져야 한다. 그런데 부분수열을 나누면

a2k = (-1)2k = 1,　a2k-1 = (-1)2k-1 = -1

이 된다. 짝수 번째 부분수열은 1로 수렴하고 홀수 번째 부분수열은 -1로 수렴하므로 전체 수열은 수렴하지 않는다. 따라서

limn→∞ (-1)n은 존재하지 않으며, 이 수열은 발산한다.

틀린 줄을 표시하고 조건을 다시 확인한 과정

  • 틀린 줄 표시: “항이 0으로 가까워진다”에 밑줄을 그었다.
  • 변수 관계 확인: n의 홀짝에 따라 항의 부호가 달라지는지 확인했다.
  • 식 수정: a2k = 1, a2k-1 = -1로 다시 정리했다.
  • 검산: n = 2, 4, 6에서는 모두 1이고 n = 1, 3, 5에서는 모두 -1임을 대입해 확인했다.

이후 학생은 절댓값이 일정하거나 유계라는 사실만으로 수렴한다고 판단하지 않도록 했다. 예를 들어 an = (-1)n/n은 부호가 번갈아도

|an| = 1/n → 0

이므로 샌드위치 정리에 의해 an → 0이다. 반면 an = (-1)n은 절댓값이 1로 유지되어 0으로 압축되지 않는다. 부호 변화와 항의 크기 변화를 분리해 보아야 하는 이유다.

두 부분수열의 극한이 각각 5와 1로 다르므로 bn은 수렴하지 않는다. 단순히 상수항 3이 포함되었다고 해서 3으로 수렴하는 것이 아니며, n의 홀짝에 따른 두 값의 차이가 발산을 결정한다는 점까지 독립적으로 확인했다.
