학생은 직각삼각형에서 두 변의 길이가 6, 8이라고 적힌 문제를 보고 곧바로 “sin은 6/10”이라고 썼다. 그림의 왼쪽 아래 각을 기준으로 하면 맞을 수 있는 답이지만, 실제 문항에서 구하라고 한 각은 오른쪽 아래 각이었다. 같은 삼각형, 같은 변의 길이라도 기준각이 달라지면 대변과 인접변의 역할이 바뀐다. 구리중3수학과외에서는 삼각비 공식을 외웠는지만 확인하지 않고, 학생이 기준각을 바꾼 문제에서 어떤 변을 먼저 선택하는지 살핀다.

6-8-10 삼각형에서 답이 달라지는 지점

직각삼각형의 두 직각변이 6과 8이면 빗변은 10이다. 왼쪽 아래 각을 A, 오른쪽 아래 각을 B라고 하자. A를 기준으로 길이 6인 변이 대변이고 8인 변이 인접변이므로

sin A = 6/10, cos A = 8/10, tan A = 6/8

이다. 그러나 B를 기준으로 보면 대변과 인접변이 서로 바뀐다.

sin B = 8/10, cos B = 6/10, tan B = 8/6

학생이 처음 쓴 “sin은 짧은 변을 분자로 쓴다”라는 설명은 공식처럼 보이지만 기준각이 바뀌면 즉시 틀린다. sin의 분자는 항상 대변이지만, 대변은 숫자의 크기로 정하는 것이 아니라 기준각과 마주 보는 위치로 정한다.

공식보다 먼저 기준각에 표시하기

학생의 풀이를 수정할 때 “다시 외워라”라고 하지 않는다. 문제에서 구하는 각에 동그라미를 하고, 그 각에서 직각으로 마주 보는 변에는 ‘대’, 각과 빗변이 아닌 나머지 변에는 ‘인’이라고 직접 표시하게 한다. 직각 표시가 있는 변은 기준각이 바뀌어도 빗변이므로 따로 ‘빗’이라고 적는다.

예를 들어 기준각이 A일 때 tan A를 구한다면 A에서 출발해 마주 보는 변을 찾고, 빗변이 아닌 옆 변을 찾는다. 따라서 tan A = 대변/인접변 = 6/8 = 3/4이다. 기준각이 B로 바뀐 같은 그림에서는 tan B = 8/6 = 4/3이 된다. 두 값이 서로 역수라는 사실을 기억하는 것보다, 왜 분자와 분모가 바뀌었는지를 설명하는 편이 새로운 도형에 더 잘 연결된다.

기준각을 먼저 표시하고, 직각 맞은편의 변은 빗변으로 고정한다. 남은 두 변 중 기준각과 마주 보는 변이 대변이다.

학생은 위아래가 바뀐 그림이나 삼각형이 회전된 그림에서 자주 멈춘다. 익숙한 모양에서 외운 “왼쪽 변은 대변”이라는 기억을 사용하기 때문이다. 하지만 대변과 인접변은 종이에 놓인 방향으로 결정되지 않는다. 기준각과의 관계로만 정해진다.
