부분합의 식이 바뀌면 일반항도 구간별로 확인한다

다음과 같이 부분합이 주어졌다고 하자.

Sn = 3n2 − n + 2

학생은 첫 항도 차분으로 구한다며 a1 = S1 − S0이라고 적었다. 하지만 문제에서 S0을 정의하지 않았다. 부분합은

Sn = a1 + a2 + ··· + an

이므로 첫째 항은 바로 a1 = S1이다.

S1을 계산하면

a1 = S1 = 3 − 1 + 2 = 4

이고, n ≥ 2에서는 인접한 두 부분합의 차를 사용한다.

an = Sn − Sn−1
= (3n2 − n + 2) − {3(n−1)2 − (n−1) + 2}
= 6n − 4

따라서 일반항은 a1 = 4, n ≥ 2에서 an = 6n − 4로 정리된다. 실제로 n=2이면 a2=8이고, S2−S1=10−4=6이므로 계산을 다시 확인해야 한다.

위 계산에서 괄호를 정확히 전개하면

Sn−1 = 3(n−1)2 − (n−1) + 2
= 3n2 − 7n + 6

이므로

an = (3n2−n+2) − (3n2−7n+6) = 6n−4

이다. n=2에서 a2=8, S2=12−2+2=12, S1=4이므로 S2−S1=8로 일치한다.
