파주고1수학과외: 분수식을 나눗셈해 유리함수의 이동형태 읽기

야당동·목동동·금촌동처럼 학교와 귀가 동선이 달라지는 생활권에서는 짧은 시간에 학교 프린트의 풀이 흔적을 점검하는 습관이 필요하다. 유리함수 단원에서는 계산 결과만 적는 것보다 분수식을 나눗셈하여 그래프의 이동형태로 바꾸었는지 확인해야 한다.

식은 바뀌었지만 정의역은 그대로 남는다

다음 함수를 살펴보자.

y = (2x + 3) / (x - 1)

분자를 분모와 관련된 식으로 나누면

2x + 3 = 2(x - 1) + 5

이므로

y = 2 + 5 / (x - 1)

가 된다. 따라서 기본함수 y = 5/x를 오른쪽으로 1, 위로 2만큼 평행이동한 형태로 해석할 수 있다. 다만 원래 식에서 분모가 0이 될 수 없으므로 x ≠ 1이라는 조건은 변형한 뒤에도 반드시 남는다. 그래프의 수직점근선은 x = 1, 수평점근선은 y = 2이다.

답안에서 사라진 한 줄

학교 프린트의 조건이 “정의역과 점근선을 함께 쓰라”였는데, 학생은 다음처럼 계산했다.

2x + 3 = 2(x - 1) + 5
y = 2 + 5/(x - 1)
수직점근선 x = 1, 수평점근선 y = 2

계산 자체는 맞지만, 원래 식의 조건인 x ≠ 1을 답안에 적지 않았다. 또 풀이 여백에도 분수식을 나눗셈해 이동형태로 바꾸었는지 표시한 흔적이 없어, 조건이 추가된 문제에서 어느 부분을 다시 확인해야 하는지 드러나지 않았다. 현재 상태는 식의 변형과 점근선 판단은 가능하지만, 변형 전 식의 제한 조건까지 풀이의 일부로 관리하지 못하는 단계다.

나눗셈 결과 옆에 조건을 붙이는 훈련

이 유형에서는 계산을 시작하기 전 원래 분모를 먼저 적는다.

  • 원래 분모: x - 1
  • 제외할 값: x ≠ 1
  • 나눗셈 변형: 2x + 3 = 2(x - 1) + 5
  • 이동형태: y = 2 + 5/(x - 1)

학생이 직접 풀이 옆에 “분수식 나눗셈 → 이동형태 확인”이라고 표시하고, 그 아래에 “원래 분모 x-1 ≠ 0”을 적게 한다. 이후 변형식에서 x = 1을 대입하면 분모가 0이 되므로 여전히 정의되지 않음을 확인한다. 이렇게 하면 식을 바꾸었다고 해서 원래 조건까지 사라지는 오류를 막을 수 있다.

조건이 붙은 그래프 문제에서 달라지는 줄

이후 문제에서 “그래프가 점 (3, 7)을 지나고, 정의역은 x ≠ 3인 유리함수의 식을 구하라”고 조건을 바꾸었다고 하자. 이동형태를

y = a + b/(x - 3)

로 두면 점근선 조건에서 수직점근선은 x = 3이다. 점 (4, 7)을 지나는 경우에는

7 = a + b/(4 - 3) = a + b

가 되므로, 점 하나만으로는 a와 b를 각각 정할 수 없다. 따라서 수평점근선이나 다른 점에 대한 조건이 추가로 필요하다. 이처럼 좌표값이나 정의역 조건이 바뀐 문제에서는 기존 풀이를 그대로 옮기지 말고, 분모의 제외값을 적는 줄과 이동형태를 정하는 줄을 먼저 표시해야 한다.

새 계산·자료·설명 문제에서 확인할 내용

변형 확인에서는 식의 계수와 좌표를 바꾼다.

y = (3x - 8)/(x + 2)

에 대해

3x - 8 = 3(x + 2) - 14

이므로

y = 3 - 14/(x + 2), x ≠ -2

이다. 학생이 수직점근선 x = -2, 수평점근선 y = 3을 설명하고, 원래 분모에서 제외값을 찾아 적는다면 수정한 행동을 새로운 식에도 적용한 것이다. 그래프 자료를 보고 점근선을 말하거나, 주어진 식을 이동형태로 계산하는 문제에서도 같은 확인 표시가 다시 나타나는지 살핀다. 풀이를 재현하지 못한 문제만 따로 남겨 조건 확인과 나눗셈 변형을 다시 점검한다.
