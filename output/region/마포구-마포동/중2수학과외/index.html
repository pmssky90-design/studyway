계산 반복보다 먼저 확인할 것

예를 들어 주머니에 빨간 공 3개와 파란 공 2개가 들어 있고, 공 1개를 꺼낼 때 빨간 공이 나올 확률을 구한다면 전체 공의 수는 5개, 원하는 경우는 3개이므로 확률은 3/5이다. 학생은 이 문제를 다시 계산하면서도 ‘전체 경우가 공 5개인가’, ‘빨간 공을 원하는 경우로 잡았는가’를 확인하지 않고 분수 계산만 반복할 수 있다.

여사건 문제에서는 이런 오류가 더 잘 드러난다. 주사위 한 개를 던져 3의 배수가 나오지 않을 확률은 3의 배수가 나오는 경우가 2개이므로 여사건을 이용해 1-2/6=4/6=2/3으로 구할 수 있다. 이때 1은 주사위의 전체 결과 6개를 기준으로 한 확률이어야 한다. 전체 결과를 3개로 잘못 잡으면 여사건 계산 자체는 맞아 보여도 의미가 달라진다.

오답 옆에 ‘계산 실수’만 쓰지 않기

시험 직전 학생은 틀린 문제 옆에 ‘계산 실수’라고만 적고 넘어가기 쉽다. 그러나 확률 오답은 서로 다른 원인으로 나누어야 한다.

  • 개념 오류: 여사건의 확률을 1에서 빼야 한다는 관계를 사용하지 못한 경우
  • 조건 누락: ‘적어도 한 번’이나 ‘두 번 모두’ 같은 조건을 빠뜨린 경우
  • 경우 누락·중복: 결과를 나열하면서 같은 경우를 두 번 세거나 하나를 빼먹은 경우
  • 확률 설정 오류: 원하는 경우와 전체 경우의 기준이 서로 다른 경우
  • 계산 오류: 분수의 덧셈·뺄셈 또는 약분 과정에서 틀린 경우
  • 표현 오류: 답은 구했지만 어떤 사건의 확률인지 설명하지 않은 경우
  • 시간 손실: 경우를 지나치게 오래 나열해 뒤 문제를 풀 시간이 부족한 경우

오답 기록에는 원인 하나와 다음 문제에서 확인할 행동 하나만 적는다. 예를 들어 ‘확률 설정 오류-전체 결과를 먼저 괄호로 표시’처럼 작성한다. 이렇게 해야 다음 풀이에서 실제 행동으로 연결된다.

전체 경우를 정하는 세 단계

첫째, 문제에서 결과를 만드는 단위를 표시한다. 주사위라면 눈의 수, 동전이라면 앞면과 뒷면, 두 번 뽑기라면 첫 번째와 두 번째 결과를 따로 적는다.

둘째, 전체 경우를 빠짐없이 나열하거나 수형도로 나타낸다. 동전을 두 번 던지는 경우에는 앞앞, 앞뒤, 뒤앞, 뒤뒤로 전체 4가지가 된다. ‘앞면이 적어도 한 번’은 앞앞, 앞뒤, 뒤앞의 3가지이므로 확률은 3/4이다. 뒤집어 여사건을 사용하면 ‘앞면이 한 번도 나오지 않음’은 뒤뒤 한 가지이므로 1-1/4=3/4이다.

셋째, 원하는 경우와 전체 경우가 같은 기준으로 세어졌는지 확인한다. 첫 번째 동전 결과만 세어 놓고 두 번 던진 전체 경우 4개와 비교하면 안 된다. 학생은 풀이 중간에 ‘전체: 4, 원하는 경우: 3’처럼 기준을 한 줄로 남긴다.

풀이를 바꾸어 보는 사례

문제: 주사위 한 개를 두 번 던질 때 적어도 한 번 6이 나올 확률을 구하여라.

한 학생은 6이 나오는 경우를 첫 번째와 두 번째로 나누어 1/6+1/6=1/3이라고 답했다. 이 답은 두 번 모두 6이 나온 경우를 두 번 포함한 경우 중복 오류다. 먼저 수형도를 그리면 전체 경우는 36가지이다. 6이 한 번도 나오지 않는 경우는 첫 번째와 두 번째 모두 1부터 5까지인 25가지다. 따라서 적어도 한 번 6이 나올 확률은 1-25/36=11/36이다.

수정할 때 학생은 ‘적어도 한 번’에 밑줄을 긋고, 여사건을 ‘6이 한 번도 안 나옴’으로 바꾼다. 이어 전체 경우 6×6, 여사건 5×5를 적은 뒤, 마지막에 원래 조건으로 돌아와 답이 적어도 한 번 6이라는 뜻인지 문장으로 확인한다.

새 조건으로 독립 검증하기

같은 문제를 다시 맞히는 것으로 끝내지 않는다. 숫자와 조건을 바꾼 새 문제를 제시한다. 예를 들어 주사위를 세 번 던질 때 4가 한 번도 나오지 않을 확률을 묻는다. 전체 경우는 6³=216, 4가 한 번도 나오지 않는 경우는 5³=125이므로 확률은 125/216이다. 반대로 4가 적어도 한 번 나올 확률은 1-125/216=91/216이다.

이때 학생이 수형도를 전부 그리지 않고도 전체 경우와 여사건의 경우를 올바르게 설정하는지, ‘적어도’와 ‘한 번도’의 조건을 바꾸어 읽는지 확인한다. 시간 제한을 두고 분수 계산 뒤 원래 조건에 답을 대입하듯, 자신이 구한 확률이 문제의 사건을 설명하는지도 말하게 한다.
