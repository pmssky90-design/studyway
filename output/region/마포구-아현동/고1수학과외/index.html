그래프 방향을 먼저 결정해야 하는 이유

y=ax²에서 x²은 항상 0 이상이다. 따라서 a가 양수이면 y값이 0 이상이 되어 꼭짓점 (0, 0)에서 위쪽으로 뻗는다. 반대로 a가 음수이면 y값이 0 이하가 되어 아래쪽으로 열린다.

a의 절댓값은 넓이와 폭을 바꾸지만, 그래프의 위아래 방향은 a의 부호가 결정한다.

예를 들어 y=4x²와 y=-4x²는 |a|가 같으므로 폭은 같지만 방향은 서로 반대다. 숫자 4만 보고 같은 방향으로 그리면 부호와 그래프의 관계를 놓치게 된다.

a=-3, 따라서 a<0 → 아래로 열린다.
|a|=3>1 → y=x²보다 좁다.

그 다음 x=1과 x=-1을 대입한다.

  • x=1이면 y=-3×1²=-3
  • x=-1이면 y=-3×(-1)²=-3
