학생이 멈춘 지점은 ‘전체 문장’이 아니었다

한 학생은 선지의 앞부분이 지문 내용과 맞는 것을 확인하면 정답에 가까워졌다고 생각했다. 그러나 이어지는 서술형 영작에서 장면에 맞는 단어를 직접 골라야 하자 철자가 비슷한 어휘를 뜻 확인 없이 바꾸어 썼다. 마지막 검토에서도 처음 세운 기준을 의심하지 않아 같은 오답을 그대로 유지했다.

훈련에서는 틀린 문장을 지우고 넘어가지 않는다. 원문 아래에 고쳐 쓴 문장을 한 줄로 다시 적은 뒤, 선택한 단어와 바꾼 단어를 나란히 비교한다. 먼저 명사·동사·형용사처럼 품사를 확인하고, 그다음 문장 전체의 뜻을 완성하는 단어인지 살핀다. 마지막으로 특정 전치사나 동사와 자연스럽게 결합하는지도 점검한다.
