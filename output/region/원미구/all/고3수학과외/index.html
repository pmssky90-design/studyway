P(-7 ≤ X ≤ 2) = P(-7/3 ≤ Z ≤ 2/3)

수직선에서 평균과 경계를 먼저 확인하기

-7 ≤ X ≤ 2, 평균 μ = -4, 표준편차 σ = 3

따라서 표준화 식은

z = (x - μ) / σ = (x + 4) / 3

이고, 양 끝점은

(-7 + 4) / 3 = -1,   (2 + 4) / 3 = 2

가 된다. 그러므로

P(-7 ≤ X ≤ 2) = P(-1 ≤ Z ≤ 2)
