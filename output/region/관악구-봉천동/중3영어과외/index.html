봉천동중3영어과외, 외운 발표문을 복합문장 답변으로 바꾸는 조건 분리 훈련

“I think the book that my teacher recommended is useful.”라는 문장을 외운 학생에게 “왜 유용하다고 생각하나요?”라고 물으면, 준비한 문장 전체를 처음부터 다시 말하는 경우가 있다. 질문이 조금만 달라져도 이미 알고 있는 표현을 꺼내지 못하고, 문장 안에 긴 수식어가 들어가면 주어와 동사를 다시 찾느라 답변이 늦어진다. 봉천동중3영어과외에서 중3 학생에게 필요한 것은 발표문을 더 많이 외우는 일이 아니라, 복합문장의 조건을 나누어 새 질문에 맞게 조합하는 과정이다.

중3 수행평가에서 바뀌어야 하는 학습 기준

현재 학생은 발표문을 보고 문장 순서와 억양을 재생하는 데에는 익숙하다. 그러나 수행평가 질문이 대본의 표현과 달라지면 핵심 내용을 유지한 채 문장 구조를 바꾸지 못한다. 수행평가 일정이 지필시험과 겹치면 외운 문장을 반복하는 시간이 늘고, 반대로 복합문장의 구조를 확인할 시간은 줄어든다. 이때는 학습량만 늘리기보다 한 문장을 어떤 순서로 해석하고 다시 만드는지 기준을 바꿔야 한다.

특히 중3에서는 학교 자료의 긴 문장, 서술형 답안, 수행평가 질문이 서로 다른 형태로 나타날 수 있다. 발표문에서 익힌 표현이 그대로 나오지 않아도 핵심어와 문장 뼈대를 분리할 수 있어야 한다. 수면이 줄어든 상태에서 대본을 무작정 반복하면 다음 문장으로 넘어갈 때 확인 절차가 더 쉽게 생략되므로, 짧은 단위로 구조를 판단하고 정해진 시점에 종료하는 방식이 필요하다.

한 문장을 외운 순서와 판단 순서는 다르다

학생이 다음 문장을 발표문에서 외웠다고 가정해 보자.

The project that our class completed last month shows how students can solve a problem together.

문장을 통째로 외우면 that 뒤의 completed를 본동사처럼 처리하거나, shows를 빠뜨린 채 긴 주어만 말할 수 있다. 이 문장에서 먼저 확인할 것은 단어의 뜻이 아니라 조건의 순서다.

  • 첫째, 핵심 주어와 본동사를 찾는다: The project / shows
  • 둘째, that our class completed last month를 project를 설명하는 삽입 정보로 묶는다.
  • 셋째, shows 뒤의 내용인 how students can solve a problem together를 하나의 설명 단위로 확인한다.
  • 넷째, 질문이 바뀌면 핵심어를 유지하고 필요한 부분만 새로 조합한다.

이 순서를 학생이 직접 말할 수 있어야 한다. “completed가 주동사가 아닌 이유는?”이라고 물었을 때 “that 뒤에서 project를 설명하는 절 안에 있기 때문”이라고 답하지 못한다면, 문장을 맞힌 것과 구조를 이해한 것은 아직 구분해야 한다.

오답 기록을 문장 단위가 아니라 조건 단위로 펼치기

시험 후 오류 기록에는 틀린 답만 옮기지 않는다. 대본의 순서가 바뀌었는지, 질문이 요구한 정보가 무엇인지, 핵심 주어와 본동사를 찾았는지 표시한다. 예를 들어 “What did the project show?”라는 질문에 학생이 발표문 전체를 말하다가 답을 놓쳤다면, 내용 암기 부족으로 적지 않고 ‘질문이 요구한 동사 show의 목적 내용을 먼저 분리하지 못함’이라고 기록한다.

그 다음 대본을 덮고 핵심어 세 개만 남긴다. 예를 들어 project, completed, solve를 제시한 뒤 “Who completed the project?”와 “What does the project show?”를 각각 묻는다. 학생은 첫 질문에 Our class completed it이라고 답하고, 두 번째 질문에는 The project shows how students can solve a problem together라고 새로 구성한다. 원래 발표문과 단어 순서가 달라도 주어, 동사, 설명의 관계가 유지되는지 확인한다.

여기서 필요한 선수개념이 that절의 기본 구조라면 해당 부분만 짧게 되짚는다. 중1·중2 문법 전체를 다시 시작하지 않고, 현재 문장에서 선행사를 설명하는 절과 주절을 구별하는 데 필요한 만큼만 확인한다. 확인이 끝나면 반드시 원래 오답 문장으로 돌아와 직접 표시하고 다시 말하게 한다.

정답을 알려주기 전 거치는 네 번의 확인

복합문장 답변을 만들 때는 다음 절차를 고정한다.

  • 질문에서 요구하는 정보에 밑줄을 긋는다.
  • 답변의 핵심 주어와 본동사를 먼저 말한다.
  • 긴 수식어 또는 설명절을 괄호로 분리한다.
  • 분리한 내용을 다시 연결해 문법적으로 끝난 문장으로 말한다.

학생이 “The project that our class completed last month…”에서 멈추면 바로 정답을 완성해 주지 않는다. “이 부분은 무엇을 설명하고 있나?”, “아직 빠진 주동사는 무엇인가?”를 묻고, shows를 찾아 문장을 끝내게 한다. 이후 답을 쓴다면 관계절의 동사와 주절의 동사를 서로 다른 색으로 표시한다. 이렇게 해야 다음 문제에서 긴 수식어가 다시 붙어도 같은 오류를 단순 반복하지 않는다.

수행평가 직후에 확인하는 독립 적용

수행평가가 끝난 직후 원래 대본을 다시 외우게 하는 것으로 검증을 마치지 않는다. 같은 핵심어를 사용하되 질문과 주어를 바꾼다. “What did your class complete?”에는 Our class completed the project last month라고 답하게 하고, “Why is the project meaningful?”에는 The project is meaningful because it shows how students can solve a problem together처럼 새로운 문장을 구성하게 한다. 학교에서 요구한 표현 범위와 문맥에 따라 답의 형태가 달라질 수 있으므로, 한 문장만 정답이라고 단정하지 않고 질문의 조건을 충족하는지 본다.

시간을 하루 이상 둔 뒤에는 대본에 없는 질문을 제시한다. 어휘 하나를 바꾸거나 수식어의 위치를 달리한 지필형 변형문제에서 학생이 핵심 구조를 표시하고, 제한 시간 안에 답을 완성하는지 확인한다. 정답을 맞혔더라도 주어·본동사·설명절의 역할을 설명하지 못하면 해결된 것으로 기록하지 않는다. 반대로 새로운 조건에서 도움 없이 문장을 만들고 이유까지 말하면 해당 오답은 복습 목록에서 뺀다.
