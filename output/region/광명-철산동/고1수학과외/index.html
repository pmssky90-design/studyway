곱셈을 시작하기 전, 크기부터 적는다

예를 들어

A = [ [1, -2, 0], [3, 4, -1] ],   B = [ [2, 5], [-1, 3], [4, 0] ]

라면 A는 2×3 행렬이고 B는 3×2 행렬이다. 앞 행렬의 열 수 3과 뒤 행렬의 행 수 3이 같으므로 AB는 계산할 수 있으며, 결과는 2×2 행렬이다.

학생은 이 크기를 적지 않은 채 곧바로 계산하면서 2×3을 3×2처럼 읽고, “행의 수가 다르므로 곱할 수 없다”고 판단했다. 행과 열을 바꾸어 읽은 것이 오류의 출발점이다. 곱셈 가능 여부는 바깥쪽 수가 아니라 앞 행렬의 열 수와 뒤 행렬의 행 수로 결정한다.

(AB)의 2행 1열에는 네 수만 들어간다

(AB)2,1만 구한다면 A의 2행과 B의 1열을 골라 대응하는 항끼리 곱해 더한다.

A의 2행은 [3, 4, -1], B의 1열은 세로로 [2, -1, 4]이다.

(AB)2,1 = 3×2 + 4×(-1) + (-1)×4 = 6 - 4 - 4 = -2

따라서 결과 행렬의 나머지 원소까지 계산할 필요는 없다. 행렬의 크기를 먼저 적은 뒤, 요구된 위치의 행과 열에 표시를 남기는 것이 이 유형에서 필요한 구체적인 행동이다.

여백에 남겨야 할 계산 흔적

  • A: 2×3, B: 3×2라고 적어 곱셈 가능 여부를 확인한다.
  • 요구된 결과 원소의 행 번호를 앞 행렬에서 찾는다.
  • 열 번호를 뒤 행렬에서 찾는다.
  • 같은 위치의 항끼리 곱한 뒤 모두 더한다.

예를 들어 문제에 “(AB)2,1의 값을 구하여라”라고 쓰여 있으면, 전체 AB를 먼저 만들지 않고 바로 A의 2행과 B의 1열을 연결한다. 이 과정을 표시하지 않았던 학생에게는 정답을 외우게 하기보다, 각 숫자 위에 ‘2행’, ‘1열’을 직접 표시하게 하여 행과 열의 역할을 분리하도록 했다.

C = [ [2, -1, 5], [0, 3, 4], [-2, 1, 6] ],   D = [ [1, 2, 0, -3], [4, -1, 2, 5] ]

C는 3×3, D는 2×4이므로 CD는 정의되지 않는다. 앞 행렬 C의 열 수 3과 뒤 행렬 D의 행 수 2가 다르기 때문이다. 여기서 학생이 행렬을 뒤집어 읽어 DC를 계산하려 한다면, 문제에 적힌 곱의 순서가 CD인지 먼저 되돌아가야 한다.

표현을 바꾸어 “C의 행과 D의 열을 대응시킬 수 있는가?”라고 물었을 때도 같은 결론을 내리는지 확인한다. 학교 프린트와 문제집에서 기호나 질문 순서가 달라도, 앞 행렬의 열과 뒤 행렬의 행을 비교하는 판단을 유지해야 한다.
